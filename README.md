# Hotelzinho Castelo

Rascunho de site institucional responsivo para apresentar ao Hotelzinho Castelo.

## Abrir localmente

Abra `index.html` no navegador. O site não precisa de instalação ou processo de build.

## Conteúdo usado

- Informações públicas visíveis no perfil do Instagram fornecido: atendimento de 6 meses a 8 anos, desde 2015, endereço e perfil `@hotelzinho.castelo`.
- Recortes da logo e de três fotos presentes na pasta `Base`.
- Botões de WhatsApp apontam para o link compartilhado no perfil: `wa.me/message/5DV3SMECIX2TO1`.

Este projeto é um rascunho de apresentação. Confirme com a equipe os textos, endereço e links de contato antes de publicar.

As capturas originais em `Base/` ficam no computador e estão excluídas do Git; somente os recortes usados no site ficam em `assets/`.

## Página de cardápio

`cardapio.html` apresenta uma simulação mensal em quatro semanas. Os pratos são exemplos ilustrativos e devem ser substituídos pelo planejamento real da creche antes de qualquer publicação como conteúdo oficial.
